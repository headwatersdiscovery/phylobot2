Why Reconstruct Ancestors

  • AI & Generative Protein Design

    Ancestors are functional sequences, filtered by evolution, that modern databases do not hold: stable scaffolds to start from, and out-of-distribution data for training generative models and testing fitness predictors.

  • Gene Therapy & Vector Engineering

    Ancestral capsids and viral enzymes, such as AAVs and Cas endonucleases, are robust starting templates with better packaging, new PAM specificities, or less pre-existing immune recognition.

  • Evolutionary & Mechanistic Biology

    Find the mutations behind a historical shift in function, an allosteric transition or an adaptation, without getting lost in modern neutral drift.

Confidence You Can Measure

An ancestor is an estimate. PhyloBot 2 is built so you can see how far to trust one.

  • One Alignment Is One Opinion

    Every combination of aligner, tree and model runs as its own traceable analysis, ranked by BIC, with the same ancestor matched across all of them.

  • Tested Against Known Answers

    The pipeline is tested continuously on simulated families whose true ancestors are known, and thresholds on those tests guard every change.

  • Gaps Placed on Purpose

    Five ways to decide where an ancestor had no residue, each scored on simulations with insertions and deletions. The unmasked reconstruction is always kept.

  • Pinned, Local, Open

    Every tool is pinned to an exact version. It runs on your own computer with no account, and nothing leaves it unless you ask for a lookup, such as a homolog search.

Quick Start

Needs Docker and make. Three commands, then open http://localhost:8000.

Run on Your Local Computer

curl -L {{ site.repository }}/releases/latest/download/phylobot.tar.gz | tar xz
cd phylobot
make up

Downloads PhyloBot and starts it. The first run builds the images, so allow a while.

Developers: Clone the Repository

git clone {{ site.repository }}.git

For development, or to follow updates with git pull. PhyloBot is open source under the BSD 3-Clause License; feel free to edit or expand its code, but please cite and attribute our work.
