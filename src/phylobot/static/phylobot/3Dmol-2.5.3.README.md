# 3Dmol.js 2.5.3

`3Dmol-2.5.3.min.js` draws protein structures on the structure page (`structure.js`).
David Koes and contributors, BSD 3-Clause licence: https://github.com/3dmol/3Dmol.js
(Rego & Koes 2015, *Bioinformatics* 31:1322, doi:10.1093/bioinformatics/btu829).

The file is `build/3Dmol-min.js` of the npm package `3dmol@2.5.3`, unchanged, served from
here so pages make no outside requests.
