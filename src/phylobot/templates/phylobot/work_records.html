Work Records

Each finished job's estimated work beside the CPU time it used, stage by stage{% if not local_mode %}, for every user{% endif %}: the data the work estimate learns from. A stage counts each step once, as the estimate does (steps that finished or were reused from an earlier attempt); failed steps and retries are only in the job's total.

{% if seconds_per_unit %}One work unit is {{ seconds_per_unit|duration }} of CPU time here, the median over the last {{ learned_from }} successful job{{ learned_from|pluralize }} (at most {{ history }}, marked ●).{% else %}This server is not calibrated yet, so ratios use the reference machine's {{ per_unit|duration }} per unit.{% endif %} A ratio is CPU time used ÷ (units × that time): 1 means the estimate was right. Jobs from before input sizes were recorded have no estimate per stage, only the job's.
