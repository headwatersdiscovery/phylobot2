    Gaps in ancestral sequences Gaps in ancestral sequencesAncestors are always reported as reconstructed, with a residue at every alignment column (ancestors.fasta). Each method ticked here also writes a copy with the columns it judges absent in each ancestor masked as gaps (ancestors.gaps-<method>.fasta).Parsimony and ML only mask: they change no residue, tree or alignment. PRANK and GRASP instead reconstruct the ancestors themselves (their own residues and gaps) on the same alignment and tree.Both parsimony rules are ticked by default: Fitch uses the outgroup's root when there is one (on simulated data it then places gaps better), shared presence needs no root.

    {{ form.gap_methods }}

    Sequence properties Sequence propertiesMeasures each ancestor's charge, hydrophobic moment and hydrophobic regions — not once, but over draws from the reconstruction's own posterior, so each property comes with the spread its uncertainty implies rather than a single number.On by default: measured on the bundled example it took 39 s of a 78 s job, since it measures every ancestor in every gap version.Draws are taken per alignment column independently, which is what the posteriors give; that is stated beside the results.
