Calibrated probabilities. At each site IQ-TREE's probabilities are raised to the power 1/T and renormalised, with T from the site's branch lengths, rate, entropy and gaps. T above 1 spreads confidence to the alternatives, below 1 concentrates it. The order of the states never changes, so the ML sequence is the same as with raw probabilities; the tiles, support plots, AltAll and the downloads use the calibrated values. Other combinations below stay raw. {% if s %}Over its {{ s.sites }} residues T runs from {{ s.low|floatformat:2 }} to {{ s.high|floatformat:2 }} (median {{ s.median|floatformat:2 }}).{% endif %}
