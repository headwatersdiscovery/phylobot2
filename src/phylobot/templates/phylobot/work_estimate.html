Work Estimate

The New Job page estimates how much computing a job asks for, in work units. One unit is about one CPU-minute on the reference machine (the developer's laptop). Units mean the same on every PhyloBot installation, so they compare jobs; each server converts them to its own time from the jobs it has run.
