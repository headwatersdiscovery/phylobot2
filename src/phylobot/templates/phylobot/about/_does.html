What PhyloBot 2 Does

Navigating multi-step phylogenetic pipelines typically requires stitching together disparate command-line tools for multiple sequence alignment, model selection, tree inference, and ancestral state estimation. PhyloBot 2 automates this entire pipeline into a unified, reproducible workflow:

  • Automated Pipeline Execution: Seamlessly runs alignment, phylogenetic inference, evolutionary model selection, and ancestral sequence reconstruction.
  • Interactive Ancestor Exploration: Inspect reconstructed ancestral states site-by-site, evaluate marginal posterior probabilities, and track ambiguous positions across the tree.
  • Mutational Trajectory Mapping: Trace the exact substitution paths connecting ancestors to modern descendants, revealing viable evolutionary intermediates that preserve folding and function.
